# 可编辑图形交付与验证

业务流程和汇报架构图默认交付 `.excalidraw`；用户只要流程理解稿时不出图。使用当前可用的文件/绘图工具，不依赖外部技能安装。

- 生成合法 JSON，采用 Excalidraw 场景结构（type 为 excalidraw，version 为 2，elements 数组，以及 appState 和 files）；图形 schema 的 version 与 skill 版本无关。
- 使用稳定、必要的元素字段与唯一 ID。优先独立 text 元素避免绑定文字导入差异；框与文字均保持可编辑。需要箭头绑定时维护有效引用；不随意添加未知字段。
- 不嵌入个人目录、来源文档正文副本、账户标识、凭据或与图无关的元数据。业务来源与关系说明单独交付，并遵循用户保密要求。
- 文本布局按实际长度和字体检查，不能只输出框。16:9 是内容边界的宽高比，不是 Excalidraw 无限画布的固定窗口大小。

验证分两层：先检查 JSON 解析、唯一 ID、文字存在、引用有效；再在可用的 Excalidraw 环境中实际打开并检查文字、布局、箭头和编辑能力。若无可用编辑器，仅标记结构检查通过、打开与视觉验证未完成，请用户选择后续验收或替代格式；不得声称“能正常打开”已被验证。

输出文件路径、主要角色/模块、关键关系、未决项和验证状态。汇报图另附省略关系清单；业务流程图不能为美观省略必要流程。
