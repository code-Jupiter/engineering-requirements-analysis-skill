# 演示结构与大纲 `presentation_outline`

输入演示目标、听众、已选择路线、必要材料、页数和格式约束。使用结论先行、以上统下、归类分组和逻辑递进；不以这些方法为由编造观点或事实。

必须分两轮：

1. 演示思路确认稿：一句话叙事主线；每个模块的标题、讲什么、为什么放在这里、与前后模块的逻辑关系；真正需要确认的问题。不得输出最终大纲 JSON 或使用 `[PPT_OUTLINE]` 标签。
2. 用户明确确认思路后，按 `references/ppt-outline-schema.md` 输出最终 JSON，包裹在规定标签内。用户补充材料、提问题或要求调整不视为确认；页数/方向有实质变化先更新确认稿。

只参考已有材料和已确认事实；不足时提问或标明假设。输出大纲后停止，不自动制作页面。
