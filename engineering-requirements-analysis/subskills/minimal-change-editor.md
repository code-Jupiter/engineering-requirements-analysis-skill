# 需求变更最小修改 `minimal_change_editor`

本能力只服务于“已有需求说明书变更工作流”的用户确认之后。根据已确认的影响面矩阵，对当前需求说明书执行最小范围修改。它不同于 `optimization_editor`：前者处理既有成品文档的明确需求变更，后者只处理新需求初稿经过三视角点评后确认的内容优化。

输入当前需求说明书、已确认的变更影响面矩阵、用户确认结果、必要事实和约束。独立审查问题台账和建议不是修改授权；除非已明确写入影响面矩阵或用户确认结果，否则不得据此修改正文。

执行要求：

1. 只修改影响面矩阵中确认需要修改的内容；
2. 不进行全篇润色，不改写无关内容；
3. 同步检查需求清单、流程、字段、状态、权限、异常、后台任务和附件逻辑是否需要更新；
4. 不得新增未经确认的业务事实；
5. 保留原文中未受影响的表达和结构；
6. 按影响面矩阵中确认的文件处理方式修改原文件或生成新文件。

输出候选修改文档、实际修改章节、未修改但已检查的章节、未能安全处理的事项和修改摘要。该能力不负责最终差异审查包。

如文档含验收标准、附录、业务流程图或附件，应按已确认影响面同步检查；超出矩阵的必要修改返回待确认，不自动扩大授权。
