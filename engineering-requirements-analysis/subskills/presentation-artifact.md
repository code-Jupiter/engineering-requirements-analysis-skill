# 演示制品制作与验收 `presentation_artifact`

仅在叙事、页数、代表页或样稿、交付格式与制作范围获确认后执行。输入确认后的大纲、材料、视觉基准、主文件路径和本轮改动范围。缺少代表页确认时先提议最低成本验证，不提前全量制作。

HTML 制作只维护一个已确认主文件；实验样稿单独标记，不冒充主文件。研究/分析任务不得修改主文件。修改前列出受影响页面，未经允许不扩展页数；反馈按增量重规划处理。

使用可用工具生成约定格式，不调用未收录技能。工具缺失时说明限制并请求选择，不将 HTML 默认为 PPTX，不声称无法验证的文件已通过。

交付前真实打开或渲染每一页，检查溢出、遮挡、换行、裁切、文字可读性、图形和数据证据，并核对页数。移除调试说明、操作提示及非演示内容；必要操作界面放在页面内容之外。记录逐页检查结果，修复后重新检查受影响页。无法渲染时标记未完成视觉验收，不交付为“已验证”。

输出制品路径、依据版本、影响页、逐页检查结果和未决限制。外部上传/发布仍需单独授权。
